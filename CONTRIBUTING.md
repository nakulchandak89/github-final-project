# Contributing to Simple Interest Calculator

Thank you for your interest in contributing to the Simple Interest Calculator project.

We welcome contributions that improve the functionality, usability, documentation, and overall quality of the project.

## Contributions

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

Before making a contribution, please ensure that your changes are relevant to the project and follow the existing structure and coding practices.

## How to Contribute

1. Fork the repository.
2. Clone your fork to your local system.
3. Create a new branch for your changes.
4. Make your changes and test them properly.
5. Commit your changes with a clear and meaningful commit message.
6. Push your branch to your GitHub repository.
7. Create a pull request describing the changes you made.

## Bug Reports

When reporting a bug, please provide:

* A clear description of the issue.
* Steps to reproduce the problem.
* Expected behavior.
* Actual behavior.
* Any relevant terminal output or error messages.

## Feature Requests

Suggestions for new features and enhancements are encouraged. Please explain the proposed feature, why it would be useful, and how it could improve the project.

## Documentation

Documentation improvements are welcome. This includes correcting errors, improving explanations, adding examples, or making instructions easier to understand.

## Code Changes

Please keep contributions simple, focused, and consistent with the existing project structure. Test your changes before submitting a pull request.

## Pull Requests

Pull requests should:

* Clearly describe the changes.
* Reference related issues when applicable.
* Include appropriate testing.
* Avoid unrelated changes.

Maintainers will review pull requests and may request changes before merging.

## Code of Conduct

All contributors are expected to follow the project's Code of Conduct and maintain a respectful and collaborative environment.

Thank you for helping improve the Simple Interest Calculator project.
